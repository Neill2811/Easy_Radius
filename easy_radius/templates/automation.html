Service account

Ansible is not used. Easy Radius logs into each router with the RouterOS API as this RADIUS user. The password is encrypted in the data file and is not shown after you save it. Click Apply afterwards so FreeRADIUS learns the user. The router must already use RADIUS for logins, and api-ssl (port 8729) must allow this server. Port 8728 is only a fallback.

Tasks

A task is RouterOS commands, one per line, or a YAML or JSON list of paths to set. On New task, paste commands such as /ip dns set servers=192.0.2.53. Variables such as {{ '{{ dns_servers }}' }} still work in YAML. The router list and site groups on this page are the inventory. There is no separate inventory file.
