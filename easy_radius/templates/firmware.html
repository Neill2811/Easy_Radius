Each router is compared with the latest version on its own channel: stable, long-term, testing, or development. Leave a box blank to fetch that channel from MikroTik. An upgrade saves /export first and installs on the router's current channel. It changes the channel only when you pick one below. After the router comes back, RouterBOARD firmware is upgraded when the board has a newer firmware file and the box below is ticked. CHR and x86 have no RouterBOARD firmware. Routers reboot.
